# دادهٔ آزمایشی آکادمی

داده‌های نمونه با `npm run student:demo` و متغیر محیطی `ACADEMY_DEMO_PASSWORD` ایجاد می‌شوند. اتصال از `.env` خوانده می‌شود. حساب‌ها با Better Auth و داده‌های آموزشی با Drizzle ساخته می‌شوند.

- ۱۲ شاگرد با نام‌های کاربری `demo_01` تا `demo_12`.
- لینک‌های نمونهٔ گیت‌هاب، تلگرام، لینکدین و وب‌سایت با ترکیب‌های متفاوت برای `demo_01` تا `demo_06`؛ این آدرس‌ها صرفاً نمونهٔ نمایشی‌اند و متعلق به شاگردهای واقعی نیستند. فقط فیلدهای خالی حساب‌های دمو تکمیل می‌شوند و لینک‌های ویرایش‌شده بازنویسی نمی‌شوند.
- ۴ دوره با پیشوند `[دمو]`، سرفصل، لینک گیت‌هاب و ویدیوی آموزشی.
- ۲۴ تخصیص دوره، شامل ۱۲ فعال و ۱۲ تمام‌شده.
- ۱۹۵ ارزیابی با امتیاز ۱ تا ۵، تاریخ‌های مختلف و توضیحات؛ برخی ارزیابی‌ها بدون دوره‌اند.
- شاگردان دورهٔ اول، شاگردان چنددوره‌ای، یک شاگرد بدون امتیاز و دو سابقهٔ عدم فعالیت وجود دارند. افت میانگین حذف شده؛ تاریخ‌های قدیمی برای بررسی جاب غیرفعال‌سازی قابل استفاده‌اند.

دستور، حساب ادمین و داده‌های قبلی را تغییر نمی‌دهد. نام کاربری نمونه اگر متعلق به حساب دیگری باشد، اجرا متوقف می‌شود. اجرای مجدد، حساب، تخصیص یا امتیاز تکراری نمی‌سازد و رمز حساب‌های نمونهٔ موجود را عوض نمی‌کند. تغییراتی که بعداً روی وضعیت دوره‌ها یا اطلاعات این شاگردها می‌دهید بازنویسی نمی‌شوند.

اطلاعات ورود اجرای محلی در `.backup/academy-demo-access.json` ذخیره شده است. این فایل و متغیرهای محیطی وارد Git نمی‌شوند. برای افزودن داده‌های نمونه به محیط دیگر، رمز ورود دلخواه را در محیط همان اجرا تنظیم کنید.

تعریف داده‌ها در `scripts/students/demo-data.mjs` و منطق درج در `scripts/students/seed-demo.mjs` قرار دارد. اجرای ابزار، ثبت هفتگی رتبه‌ها را جعل نمی‌کند؛ جدول رتبه‌بندی و نمودار از داده‌های زنده استفاده می‌کنند.
