# راهنمای ویرایش Prograin

| بخش                                        | مسیر                                                             |
| ------------------------------------------ | ---------------------------------------------------------------- |
| متن خانه، قیمت آموزش‌ها، پکیج‌ها و پرسش‌ها | `src/content/`                                                   |
| صفحه‌ها و آدرس‌های سایت                    | `src/app/`                                                       |
| کارت‌ها، تب‌ها و محتوای هر صفحه            | `src/features/`                                                  |
| هدر، فوتر، زبان، تم و مودال                | `src/components/`                                                |
| پروژه‌های عمومی صفحه پروژه                 | `src/features/order/projects-data.js`                            |
| سفارشی‌سازی رزومه                          | `src/features/portfolio/`، `src/resume/` و `src/content/resume/` |
| عنوان و توضیحات سئو                        | `src/content/seo/`                                               |
| داده‌های ساختاریافته                       | `src/seo/`                                                       |
| دامنه و اطلاعات تماس                       | `src/config/site.js`                                             |
| ظاهر و واکنش‌گرایی                         | `src/css/`                                                       |
| تصاویر اصلی                                | `assets/`                                                        |

فایل‌های `fa.json` و `en.json` متن هر زبان را نگه می‌دارند. شناسه‌های ثابت مثل `private` و `group` به تب‌ها و مودال‌ها متصل‌اند. تغییر قیمت در محتوای کارت، قیمت داخل مودال را هم به‌روزرسانی می‌کند.

ترتیب فایل‌های استایل در `src/css/index.css` تعیین می‌شود. کلاس هر عنصر را در `src/css/` جست‌وجو کنید. تصویر پس‌زمینهٔ خانه و تماس در فایل‌های `background.css` همان صفحه قرار دارد. برای نسخهٔ جدید عکس، فایل اصلی را در `assets/images/` جایگزین و دوباره بیلد کنید.

`npm run dev` سرور توسعه را روی پورت ۴۱۷۳ اجرا می‌کند. `npm run package` خروجی قابل انتشار را در `out/` می‌سازد. فایل‌های `out/`، `.next/` و فایل‌های تولیدشده در `public/` و `src/generated/` را مستقیم ویرایش نکنید.
