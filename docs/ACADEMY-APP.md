# وب‌اپ آکادمی

وب‌اپ نصب‌شدنی فقط از `/academy/students/` شروع می‌شود. نام برنامه **Prograin Academy**، شناسه و محدودهٔ ثابت آن `/academy/students/` و مسیر شروع، صفحهٔ ورود است. نشست معتبر، کاربر را طبق نقش فعلی به داشبورد شاگرد یا مدیریت می‌برد.

## نصب و محدوده

دراپ‌داون‌های آکادمی از کامپوننت مشترک Radix Select استفاده می‌کنند تا ظاهر منو در iOS و مرورگرهای دیگر یکسان باشد. `npm run test:student:selects` بعد از نصب WebKit با `npx playwright install webkit`، انتخاب گزینه‌ها، ارسال فرم و نمایش منو داخل مدال را با تنظیمات آیفون و هر دو تم بررسی می‌کند؛ این آزمون شبیه‌سازی مرورگر است و جای بررسی روی آیفون واقعی را نمی‌گیرد.

تم روشن فقط در بخش شاگردان، از `/academy/students/` به بعد، در دسترس و پیش‌فرض است؛ انتخاب پنل با کلید مستقل `academy_theme` ذخیره می‌شود. تمام صفحات عمومی، از جمله ورودی آکادمی و مشاوره، همیشه تیره‌اند و از استایل اصلی سایت استفاده می‌کنند. نئومورفیسم و تغییر تم به پنل محدود هستند؛ کنترل آن از هدر دسکتاپ و منوی موبایل در دسترس است. رنگ نوار مرورگر با تم انتخابی هماهنگ می‌شود؛ پس‌زمینهٔ روشن پنل از طیف آبی‌خاکستری استفاده می‌کند.

- manifest و آیکون Apple فقط در بخش شاگردان معرفی می‌شوند؛ صفحات اصلی سایت manifest نصب ندارند. `/site.webmanifest` برای سازگاری باقی مانده و همان manifest محدود آکادمی را برمی‌گرداند.
- دکمهٔ «نصب آکادمی» در فوتر بخش شاگردان، پنجرهٔ نصب مرورگر را باز می‌کند. اگر این پنجره در مرورگر موجود نباشد، راهنمای Chrome، Edge و Safari نمایش داده می‌شود. در نسخهٔ نصب‌شده، این دکمه پنهان است.
- دعوت به نصب، در هر نشست مرورگر فقط یک‌بار و پس از مکث کوتاه نمایش داده می‌شود؛ دکمه‌های «نصب آکادمی» و «فعلاً نه» دارد. هنگام تایپ یا ارسال فرم و در حضور پنجرهٔ دیگر، دعوت باز نمی‌شود. ثبت نصب و حالت standalone، دعوت خودکار را متوقف می‌کنند؛ دکمهٔ فوتر برای اقدام دستی باقی می‌ماند.
- تشخیص حالت نصب‌شده با `display-mode: standalone` و `navigator.standalone` انجام می‌شود. در این حالت، لینک‌های سایت اصلی حذف می‌شوند، پشتیبانی مستقیم به تلگرام وصل است و بازگشت فقط از تاریخچهٔ داخل آکادمی استفاده می‌کند. تاریخچهٔ برنامه هنگام ورود دوباره پاک می‌شود.
- `AcademyAppBoundary` ناوبری به صفحات اصلی همان سایت را متوقف و ورود مستقیم به مسیر بیرون از آکادمی را به صفحهٔ ورود برمی‌گرداند. منابع بیرونی مانند GitHub و YouTube با مرورگر جدا باز می‌شوند. این کنترل، مرز رابط کاربری است؛ مجوز شاگرد و استاد همچنان در بک‌اند بررسی می‌شود.
- محدودیت scope مرورگر به‌تنهایی مانع خروج نیست؛ به همین دلیل هم مسیرهای برنامه و هم لینک‌ها کنترل می‌شوند. رفتار بازشدن منابع بیرونی تابع مرورگر و سیستم‌عامل است.

## سرویس‌ورکر و حریم خصوصی

ثبت سرویس‌ورکر با Workbox Window انجام می‌شود. همان `/academy-notifications-sw.js` و scope قبلی اعلان‌ها حفظ شده‌اند تا اشتراک پوش موازی ایجاد نشود. `updateViaCache: none` و هدر بدون کش، به‌روزرسانی اسکریپت و ماژول آفلاین آن را کنترل می‌کنند.

فقط درخواست ناوبری در محدودهٔ آکادمی از شبکه دریافت می‌شود. در قطع اتصال، یک صفحهٔ عمومی بدون اطلاعات حساب نمایش داده می‌شود. صفحهٔ ورود، داشبورد، APIها، امتیازها و اطلاعات شاگردان وارد CacheStorage نمی‌شوند؛ ویرایش و ورود آفلاین ارائه نمی‌شود. ثبت سرویس‌ورکر، اجازهٔ اعلان درخواست نمی‌کند؛ پوش فقط با انتخاب کاربر فعال می‌شود.

## آیکون‌ها

منبع وکتور در `assets/icons/academy/logo.svg` است. `scripts/lib/academy-icons.mjs` با Sharp خروجی‌های ۴۸، ۱۸۰، ۱۹۲ و ۵۱۲ پیکسل را می‌سازد. آیکون ۵۱۲ پس‌زمینهٔ کامل و حاشیهٔ امن maskable دارد و آیکون Apple نیز بدون شفافیت تولید می‌شود. پس از تغییر SVG، اجرای build یا راه‌اندازی دوبارهٔ dev خروجی‌ها را بازسازی و نسخهٔ آدرس فایل‌ها را تغییر می‌دهد.

## بررسی و انتشار

```sh
npm run package
npm run test:academy:app
npm run test:notifications:worker
npm run test:students
npm run test:notifications:ui
```

تست وب‌اپ به `STUDENT_TEST_DATABASE_URL` روی دیتابیس آزمایشی مستقل نیاز دارد. manifest با DevTools مرورگر، سرویس‌ورکر واقعی، راهنمای نصب، ناوبری محدود، نقش استاد و شاگرد، تشخیص حالت iOS، بازگشت و قطع و وصل شبکه بررسی می‌شوند. حالت standalone و پنجرهٔ نصب در تست شبیه‌سازی می‌شوند؛ نصب واقعی روی دستگاه کاربر انجام نمی‌شود.

انتشار به HTTPS نیاز دارد؛ loopback برای توسعه نیز پشتیبانی می‌شود. این قابلیت مهاجرت دیتابیس یا متغیر محیطی جدید ندارد. پس از انتشار، از صفحهٔ ورود آکادمی گزینهٔ نصب را انتخاب کنید.
